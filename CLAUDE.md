Это учебный проект: Denis пишет прошивку сам. **Не писать и не править код (`.c`, `.h`, `CMakeLists.txt`) без явного запроса.** По умолчанию — объяснять, подсказывать, на что смотреть, и помогать искать причину ошибки; готовый код давать только когда об этом прямо попросили.

## Проект

Первая прошивка для платы на RP2350B формата Pi Zero (предположительно Waveshare RP2350-PiZero). Цель: плата появляется на компьютере как виртуальный COM-порт (USB CDC) и выводит в него строку `Hello Denis`.

Пошаговый план, таблица типичных неисправностей и критерий готовности — в [PLAN.md](PLAN.md).

## Стек

- Pico SDK 2.3.1 на C, проект сгенерирован расширением **Raspberry Pi Pico** для VS Code (оно же ставит тулчейн, CMake, Ninja, picotool в `~/.pico-sdk`).
- Плата в `CMakeLists.txt`: `waveshare_rp2350_pizero` (RP2350B, флеш 16 МБ). Архитектура ARM, не RISC-V.
- stdio направлен в USB, UART выключен.
- Блок в `CMakeLists.txt` между маркерами `DO NOT EDIT` нужен расширению — не трогать.

## Сборка и прошивка

- Сборка: кнопка **Compile** в строке состояния VS Code. Результат — `build\rp2350_proba.uf2`.
- Прошивка: зажать **BOOT**, подключить USB, скопировать `.uf2` на диск **RP2350** (или кнопка **Run** в расширении, плата тоже в режиме BOOT).
- На Waveshare PiZero два USB-C: нужен обычный **USB**, не **PIO-USB**.
- Проверка: COM-порт в диспетчере устройств, открыть через Serial Monitor или PuTTY с включённым DTR (иначе `stdio_usb_connected()` остаётся `false`). Перед повторной прошивкой терминал закрыть.
