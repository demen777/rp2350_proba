# План: прошивка «Hello Denis» по USB CDC для RP2350B (PiZero)

## Контекст

Цель — самостоятельно (без участия Claude, пока явно не попросишь) написать первую прошивку для платы на RP2350B формата Pi Zero (предполагаю Waveshare RP2350-PiZero). После подключения к компьютеру плата должна появиться как виртуальный COM-порт и выводить в него строку `Hello Denis`.

Папка `c:\project\rp2350_proba` пустая, проект создаётся с нуля.

Выбранный стек (моё предположение по умолчанию): **официальный Pico SDK на C** через расширение **Raspberry Pi Pico для VS Code**. Оно само ставит SDK, компилятор, CMake, Ninja и picotool — на Windows это самый короткий путь. Если хочешь MicroPython, Rust или Arduino — план будет другим, скажи.

## Шаг 1. Окружение

1. В VS Code установить расширение **Raspberry Pi Pico** (издатель Raspberry Pi).
2. Через его панель выбрать **New C/C++ Project**:
   - расположение: `c:\project\rp2350_proba`;
   - SDK: версия 2.1.0 или новее (в более старых нет RP2350B-плат);
   - плата: искать `waveshare_rp2350_pizero` в списке. Если её нет — взять `pico2` (для этой задачи разницы нет: USB и загрузка работают одинаково, отличается только число GPIO и размер флеша);
   - архитектура: ARM (не RISC-V);
   - **Stdio support: включить «Console over USB», выключить «Console over UART»**.
3. Дождаться, пока расширение скачает тулчейн (первый раз — несколько минут).

Проверка: в папке появились `CMakeLists.txt`, `pico_sdk_import.cmake`, файл `.c` и папка `.vscode`.

## Шаг 2. CMakeLists.txt

Убедиться, что в сгенерированном файле есть (и понять, что делает каждая строка):

- `set(PICO_BOARD ...)` — выбранная плата, стоит **до** `pico_sdk_init()`;
- `pico_enable_stdio_usb(<target> 1)` — направляет `printf` в USB CDC;
- `pico_enable_stdio_uart(<target> 0)` — отключает вывод в UART;
- `target_link_libraries(<target> pico_stdlib)`;
- `pico_add_extra_outputs(<target>)` — без неё не будет файла `.uf2`.

## Шаг 3. Код (main)

Написать самому, нужны три вещи из `pico/stdlib.h`:

1. `stdio_init_all()` — поднимает USB CDC. Вызвать первой.
2. Дождаться открытия порта на компьютере: цикл с `stdio_usb_connected()` и `sleep_ms()` внутри. Без этого строка уйдёт раньше, чем ты откроешь терминал, и ты её не увидишь.
3. `printf("Hello Denis\n")`.

Рекомендация: печатать строку в бесконечном цикле раз в секунду, а не один раз — так гораздо проще отлаживать. Когда заработает, можно оставить однократный вывод после ожидания подключения.

`main` не должен завершаться — в конце нужен бесконечный цикл.

## Шаг 4. Сборка

Кнопка **Compile** в строке состояния VS Code (или «Compile Project» в панели расширения).

Проверка: в `build\` появился `<имя_проекта>.uf2`.

## Шаг 5. Прошивка

1. Зажать кнопку **BOOT** на плате и, удерживая её, подключить USB-кабель к компьютеру. Отпустить.
2. В проводнике появится диск **RP2350**.
3. Скопировать на него `.uf2`. Диск исчезнет, плата перезагрузится в твою прошивку.

Альтернатива: кнопка **Run** в расширении (заливает через picotool, плата тоже должна быть в режиме BOOT).

## Шаг 6. Проверка

1. Диспетчер устройств → «Порты (COM и LPT)» → появилось «Устройство с последовательным интерфейсом USB (COMx)».
2. Открыть порт: расширение **Serial Monitor** в VS Code или PuTTY. Скорость любая (для USB CDC она не имеет значения), например 115200.
3. В терминале должна появиться строка `Hello Denis`.

## Если не работает

| Симптом | Причина |
|---|---|
| Диск RP2350 не появляется | Кабель только для зарядки; BOOT отпущен до подключения; не тот разъём — на Waveshare PiZero два USB-C, нужен обычный **USB**, не **PIO-USB** |
| Диск есть, COM-порта после прошивки нет | В CMake не включён `pico_enable_stdio_usb`, либо не вызван `stdio_init_all()`, либо `main` завершился |
| Порт есть, в терминале пусто | Строка напечатана до открытия порта (см. шаг 3, п. 2); терминал не выставляет DTR — в PuTTY/Serial Monitor включить DTR, иначе `stdio_usb_connected()` остаётся `false` |
| `.uf2` копируется, но плата снова показывает диск | Прошивка собрана под другую платформу (RP2040 или RISC-V) — проверить плату и архитектуру в шаге 1 |
| Порт «занят» при повторной прошивке | Закрыть терминал перед заливкой |

## Критерий готовности

Плата подключена обычным способом (без BOOT), в диспетчере устройств виден COM-порт, после его открытия в терминале видна строка `Hello Denis`.
